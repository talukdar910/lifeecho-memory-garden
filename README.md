# Lifeecho Memory Garden

Create a web app named LifeEcho, a global digital memory platform. The app should have a modern, premium design using green, teal, black, and white. Include user registration, an active profile status, and a dedicated section called Memory Archive for storing memories of deceased individuals. The focus should be on securely preserving stories, photos, videos, and audio for future generations
